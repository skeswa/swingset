# Curated-dataset architecture sources

Bibliographic evidence for the
[research report](../../../curated-datasets-state-of-the-art-2026-09-12.md)
and its refinements to the [proposal](../../../../design/self-healing.md).

`sources.json` lists the 21 cited primary sources, authors or publishers, URLs,
known publication/revision dates, evidence types, review depth, and applicability
limits. Source numbers correspond to the report's inline notes and Sources list.
Undated maintained documentation has an access date rather than an invented
publication date. This is a source inventory, not an archive of the remote pages;
unversioned documentation can change after the review.

The OpenSanctions Pairs assessment uses the version 2 HTML, dated August 25,
2026, which supplies the revised title and four-author list. The generic abstract
page displayed an older title/author presentation. The earlier manual-only
OpenSanctions article is explicitly historical; current identifier documentation
describes a mixed automatic and reviewed workflow. The Lam et al. preprint is
used at abstract depth and is labeled as early methodological evidence.

The report separates documented practices from recommendations for Swingset.
Neither cited documentation nor benchmark results are measurements of Swingset's
production accuracy. Runtime behavior was not changed as part of this research.
