# State the question or finding in plain language

Date: YYYY-MM-DD, with timezone when it matters  
Type: Investigation / Outcome  
Topic: Name the topic  
Related plan or decision: Link, if any

## Summary

Give the question and main finding in a few sentences. A conclusion may be
“we do not yet know.” Separate measured facts from explanations or guesses.

## Context

Explain what prompted the work and enough background for someone new.

## Findings

Describe what the evidence establishes, its scope, and remaining uncertainty.
Pin the code revision, dataset version, or environment when the result depends on it.

## Conclusion and follow-up

State what follows from the findings and what remains to do. A recommendation
is not an accepted decision; link to a separate decision record when needed.
If this replaces an earlier conclusion, link both records.

## Evidence and reproduction

Link to commands, scripts, captured sources, measurements, and reports. Store
large artifacts in `journal/evidence/<topic>/<run>/`. Do not copy credentials or private environment files.
