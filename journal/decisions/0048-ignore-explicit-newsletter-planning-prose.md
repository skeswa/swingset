# D-0048: Ignore explicit newsletter planning prose

Recorded: 2026-09-17  
Decided by: agent  
Topic: Historical source interpretation  
Supersedes: —  
Superseded by: —

## Decision

Do not report an event approval for the reviewed administrative sentences about
planning dates, managing events, applying for membership, certification, or the
council’s posting schedule. Recognize the specific wording verified in retained
full PDFs. Keep other prose, unknown layouts and quarter-only
approval notices as findings.

## Why

Volumes 8, 9, 11, 23 and 29 include “new events” in administrative prose, which
the old parser treated as an approval heading. These sentences name no approved
edition and provide no event date. Removing this false warning preserves all dated rows
and the actual undated-listing findings. A general rule that ignores every
prose mention could hide real approvals.
