## Decision

shape. Keep judge notes separate from the printed roster and retain source
group attributes when expanding anonymous columns. Require the explicit
supported preliminary legend and matching table widths. Increment event and
round extractor/parser versions to 2.

parses previously rejected a grouped header; the event capture had metadata but
no round links. Accepting arbitrary merged cells or unexplained empty output
would hide changes. Exact shapes and explicit absence findings allow useful
source observations while preserving admission boundaries.

## Consequences

request. This record does not claim owner or page-kind acceptance. No seed or
discovered watch, canonical projector, source policy, year gate, deployment or
publication is changed. Results-bearing event controls and a reviewed
cross-page ownership/promotion rule remain outstanding.
