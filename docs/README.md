the question you want to answer; you do not need to read every document.

Start with the [overview](overview.md), then the [pipeline walkthrough](how-it-works/README.md).
Each page explains its main point before linking to deeper detail.

## Which document should I trust?

Explanations teach the ideas. Reference pages own exact rules. Plans describe
work still to do; their presence does not mean a feature is running. The
[status page](status.md) distinguishes local checks, deployment, and publication.

The journal preserves what was known or decided at a particular time. Older
findings can be superseded. Read a decision's status before treating it as a
project rule. Captured evidence stays under [research](../journal/evidence/README.md).

To update these docs, follow the [writing guide](writing.md).
