# Source guides

Each guide owns the verified details for one source: what it provides, how to
find and read it, and what limits apply. Start with
[collection explained](../../how-it-works/collection.md) if the pipeline is new to you.

## Choose a source

| Source                                          | What it provides                       |
| ----------------------------------------------- | -------------------------------------- |
| [WSDC calendar](wsdc-calendar.md)               | Event dates and locations              |
| [WSDC registry](wsdc-registry.md)               | Dancers, points, and placements        |
| [WSDC newsletters](wsdc-newsletters.md)         | Historical event lists                 |
| [EEPro](eepro.md)                               | Round sheets and results               |
| [scoring.dance](scoring-dance.md)               | Results, marks, and printed dancer IDs |
| [World Dance Registry](world-dance-registry.md) | Round data and awards                  |
| [danceconvention.net](danceconvention.md)       | Event results and linked score files   |
| [Step Right Solutions](step-right-solutions.md) | Archived historical score sheets       |
| [Other event sites](long-tail.md)               | Results outside the main platforms     |
| [Wayback Machine](wayback-machine.md)           | Archived copies of source pages        |

A guide's verification date describes its evidence. Listing a source does not
mean its adapter is deployed or its history complete. Check the guide's open
items and [project status](../../status.md).

## Shared rules and source-specific detail

[Fetching](../fetching.md) owns the shared request rules. A source guide owns
only its verified details and permitted host overrides. [Backfill](../backfill.md)
owns historical selection rules. Keep configuration in step with these owners;
resolve disagreements explicitly instead of maintaining competing rule copies.

Within a guide, read what the source gives first. Then use the numbered
sections for URLs, discovery, fetching, parsing, and open items. Raw survey
counts and earlier assumptions remain in the
[original source survey](README.md).
